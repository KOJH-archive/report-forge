# 기존 회사 PPTX의 디자인 재사용

Report Forge 0.2는 원본 PPTX를 읽어 슬라이드를 복제하고 지정한 텍스트, 표, 차트 데이터를 교체합니다. 별도 AI API, 특정 IDE 플러그인이나 Office 설치 없이 실행할 수 있습니다.

## 화면에서 사용하기

1. `npm run studio`로 자료 제작 화면을 엽니다.
2. 자료 정보에서 회사 PPTX를 선택하고 **디자인 가져오기**를 누릅니다. 최대 40MB, 200장을 지원합니다.
3. 자동 선택된 원본을 확인합니다. 표지, 본문, 주요 지표, 차트, 참고 자료에 사용할 원본을 직접 선택할 수도 있습니다. 표는 열 개수가 맞는 원본을 자동 선택합니다.
4. **텍스트 교체 위치 확인**에서 제목, 부제, 본문, 출처, 페이지 번호를 확인합니다. 번호와 위치 지도는 텍스트 상자를 찾기 위한 정보입니다. 시각적 미리보기는 아닙니다.
5. 로고나 회사명처럼 남길 문구는 **디자인 문구 보존**, 기존 업무 내용처럼 지울 문구는 **기존 문구 지우기**로 설정합니다.
6. 미리보기에서 입력과 영역 크기 검증을 거친 뒤 **자료 내보내기**를 누릅니다. 설정을 다음에도 쓰려면 **원고 저장**을 누릅니다.

기본 서식으로 돌아가려면 **기본 서식 사용**을 선택합니다. 가져온 템플릿 복사본은 원고 폴더에 남습니다.

## 자동 분석과 수정

슬라이드 순서, 크기, 텍스트와 도형의 좌표, 글꼴, 자리표시자, 편집 가능한 표·차트를 읽습니다. PowerPoint의 제목·본문 자리표시자를 우선 사용합니다. 일반 텍스트 상자는 크기, 위치, 반복 문구와 숫자 형태를 보고 역할을 추정합니다. 추정이 틀릴 수 있으므로 사용자가 화면에서 고칠 수 있습니다.

원본을 직접 준비할 수 있다면 PowerPoint 선택 창에서 개체 이름을 `rf:title`, `rf:lead`, `rf:body`, `rf:footer`, `rf:page`, `rf:meta`, `rf:disclosure`, `rf:unit`, `rf:note`, `rf:keep`으로 지정할 수 있습니다. 주요 지표는 `rf:metric1.label`, `rf:metric1.value`, `rf:metric1.description`처럼 최대 3개를 지정합니다. 이름을 지정하지 않은 기존 PPTX도 자동 분석합니다.

원고의 설정 예시입니다. 슬라이드 번호는 1부터 시작하며 텍스트 상자 ID는 가져오기 화면에 표시됩니다. 표 지정이 생략되면 표의 열 개수로 원본을 고릅니다.

```json
"template": {
  "file": "templates/company/source.pptx",
  "layouts": { "cover": 1, "flow": 2, "metrics": 3, "chart": 4, "references": 2 },
  "roles": { "2": { "3": "title", "4": "lead", "5": "body", "6": "footer" } }
}
```

`design.json`은 참고용 분석 기록입니다. 생성 시 원본 PPTX를 다시 분석하고 위 설정을 적용합니다. 원본 PPTX를 교체했다면 상자 ID가 바뀔 수 있으므로 역할을 다시 확인합니다. `manifest.json`에 사용한 원본 해시와 출력 슬라이드마다 선택한 원본 번호를 기록합니다.

## 보존 및 교체 범위

- 마스터·레이아웃·테마·배경·이미지는 원본 패키지의 해당 부분을 유지합니다. 변경하지 않는 디자인 부분은 새로 그리지 않습니다.
- 텍스트는 지정한 상자의 좌표, 텍스트 영역 속성, 문단 속성과 첫 글자 서식을 재사용합니다. 한 상자 안의 여러 색상·굵기 조합은 첫 글자 서식으로 통일됩니다.
- 표는 원본의 열 너비, 헤더, 행 높이, 셀 서식을 유지하며 데이터를 교체합니다. 원본에 들어 있는 데이터 행 수를 넘으면 원본을 다시 복제한 다음 페이지에 나머지 행을 넣습니다. 짧은 마지막 페이지의 표 높이는 실제 행 수만큼 줄어듭니다.
- 선·막대 차트는 원본의 차트 영역, 선·막대 색상, 축·범례 스타일을 유지합니다. 캐시와 편집용 워크북을 새 데이터로 교체합니다. 기존 고정 축 최솟값·최댓값은 해제해 새 수치가 잘리지 않게 합니다. 개별 점의 옛 색상·라벨은 제거합니다.
- 원본 차트와 원고의 선/막대 형태가 같아야 합니다. 원고 계열 수가 원본보다 많으면 색상 중복을 피하기 위해 오류를 표시합니다. 범주와 계열 수가 줄어드는 것은 지원합니다.
- 새 발표자 노트에 본문과 전체 출처를 넣습니다. 기존 노트, 삭제된 슬라이드, 기존 차트 데이터와 미리보기 썸네일은 출력에 실리지 않습니다.

## 지원 범위와 확인할 사항

그룹 내부 텍스트, 마스터·레이아웃의 문구, 원본 이미지 및 **디자인 문구 보존**은 그대로 남습니다. 이러한 요소에 과거 업무 내용이 포함되어 있으면 먼저 PowerPoint에서 지우거나 그룹을 풀어야 합니다. 반복되는 위·아래 문구는 회사 이름이나 고정 문구로 추정될 수 있으므로 역할 설정을 확인합니다.

병합 표, SmartArt·OLE의 내용 교체, 그림으로 된 차트·표, 확장·복합·원형 차트의 데이터 교체는 지원하지 않습니다. 매크로가 없는 일반 PPTX를 사용합니다. 필요한 제목·본문·차트·표가 없거나 새 내용이 원래 영역보다 길면 오류를 표시합니다. 작은 글자로 무조건 축소하거나 내용을 생략하지 않습니다.

텍스트와 셀의 길이 검사는 좌표·글자 크기를 이용한 보수적 추정입니다. 줄바꿈과 글꼴은 PowerPoint 환경에 따라 달라질 수 있습니다. 회사 글꼴이 출력 파일을 여는 컴퓨터에 설치되어 있어야 합니다. 기존 PPTX에 포함된 글꼴 부분은 유지하지만 새 글꼴 파일을 넣지는 않습니다.

HTML 미리보기에는 기본 서식으로 원고를 표시합니다. 회사 디자인은 내보낸 PPTX에 적용됩니다. Word 보고서와 엑셀 근거 자료는 기존 Report Forge 서식으로 생성됩니다.

## 검증

자동 테스트로 4:3 원본의 분석, 이름 없는 텍스트 상자의 역할 추정, 원본 디자인 부분의 해시 보존, 오래된 내용 제거, 표의 모든 행 보존, 두 차트의 독립적인 워크북, 업로드·내보내기, 잘못된 매핑·차트 형태·경로 거절을 확인했습니다.

검증용 가상 회사 서식 6장과 새 내용으로 생성한 11장을 이미지로 변환해 모두 비교했습니다. Office 패키지 구조 검사에서도 연결 오류가 없었습니다. 이 환경에는 PowerPoint/LibreOffice가 없어 실제 Office에서의 최종 표시는 확인하지 못했습니다. 실제 회사 PPTX는 아직 제공되지 않았습니다.
